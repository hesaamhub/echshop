# Binary Inbox

پل آپلود فایل باینری از طریق MCP متنی گیت‌هاب (base64 متنِ خالص است و عبور می‌کند):

1. فایل باینری → base64 → چانک‌های ~۱۲KB با نام‌های `<name>.001.b64` و… داخل همین پوشه پوش می‌شوند
2. در آخرین پوش، `manifest.json` با این فرمت:

```json
{ "files": [ { "target": "public/art/example.png", "chunks": ["example.001.b64", "example.002.b64"] } ] }
```

3. اکشن `binary-inbox` به‌صورت خودکار decode می‌کند، فایل باینری را کامیت می‌کند و inbox را پاک می‌کند (کامیت با `[skip ci]` تا لوپ ایجاد نشود).
