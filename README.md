# اچ‌شاپ — echshop

فروشگاه اکانت و لایسنس دیجیتال، کاملاً فارسی و راست‌چین (RTL).

## تکنولوژی

- **Next.js 15** (App Router)
- **TypeScript**
- **Tailwind CSS v4**
- **Motion** برای انیمیشن
- **lucide-react** برای آیکون‌ها
- فونت **Vazirmatn** برای فارسی و **Outfit** برای اعداد و متن لاتین

## اجرای محلی

```bash
npm install
npm run dev
```

سپس نشانی `http://localhost:3000` را باز کنید.

## دیپلوی روی Vercel

1. با حساب گیت‌هاب خود در [vercel.com](https://vercel.com) وارد شوید.
2. گزینهٔ **Add New → Project** و سپس **Import** مخزن `echshop` را انتخاب کنید.
3. بدون تغییر تنظیمات، دکمهٔ **Deploy** را بزنید. متغیر محیطی لازم نیست.

لینک یک‌کلیکی:

```
https://vercel.com/new/clone?repository-url=https://github.com/hesaamhub/echshop
```

## ساختار صفحه‌ها

### فروشگاه

| مسیر | توضیح |
| --- | --- |
| `/` | صفحهٔ اصلی با هیروی ویدیویی، نوار لوگوی برندها، محصولات و مزیت‌ها |
| `/products` | فهرست محصولات با فیلتر |
| `/products/[slug]` | صفحهٔ اختصاصی محصول، انتخاب پلن و پرسش‌های متداول |
| `/category/[slug]` | محصولات هر دسته‌بندی |
| `/cart` و `/checkout` | سبد خرید و تسویه |
| `/blog` و `/blog/[slug]` | بلاگ |
| `/about` و `/contact` | درباره ما و تماس با ما |
| `/login` | ورود و ثبت‌نام |
| ۴۰۴ | صفحهٔ خطای اختصاصی |

### پنل کاربری (`/dashboard`)

پیشخوان، سفارش‌ها و تحویل، کیف پول، تیکت‌ها، اطلاع‌رسانی، علاقه‌مندی‌ها، پروفایل و امنیت.

### پنل مدیریت (`/admin`)

داشبورد، محصولات و پلن‌ها، انبار و تحویل، دسته‌بندی، سفارش‌ها، کاربران، تیکت‌ها، کدهای تخفیف، مدیریت محتوا و تصاویر، بلاگ، اطلاع‌رسانی، گزارش‌ها و تنطیمات.

## روش‌های تحویل

هر پلن می‌تواند روش تحویل جداگانه داشته باشد:

- تحویل دستی توسط پشتیبانی
- تحویل فوری از انبار
- تحویل خودکار از API تامین‌کننده
- ارتقای اکانت شخصی کاربر
- ارسال گیفت‌کد / لایسنس
- تحویل زمان‌بندی‌شده

## وضعیت فعلی

- داده‌ها فعلاً نمونه و در `src/lib/data.ts` قرار دارند؛ مرحلهٔ بعد اتصال به دیتابیس است.
- درگاه پرداخت طبق خواستهٔ شما بعدتر تنطیم می‌شود (ساختار فیلدها در تنطیمات مدیریت آماده است).
